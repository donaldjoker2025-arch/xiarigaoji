============================================================
          夏日告急 — 北航空调电量监控  使用说明
============================================================

【这是什么】
  一个跑在你自己电脑上的小工具，定时查询你宿舍/教研室电表的剩余电量，
  电量低于阈值时通过【电脑桌面通知 / 微信】提醒你，并能一键跳转学校
  官方页面充值。所有数据只存在你本机，不上传任何服务器。


【运行前提】★必看
  必须连接【北航校园网】才能查到电量（学校查询接口在校内网）。
  在校外或没连校园网时，电量会查询失败。


【怎么启动】
  1. 把「夏日告急.exe」放在一个可写的文件夹（如桌面、下载），
     不要放在 C:\Program Files 里（那里没有写入权限）。
  2. 双击「夏日告急.exe」。
  3. 第一次运行如果弹出 Windows 防火墙提示，请点【允许访问】。
  4. 程序会自动打开浏览器页面；右下角任务栏还会出现一个闪电小图标，
     右键它可以「打开面板 / 立即轮询 / 退出」。
  5. 启动后也可手动访问：http://localhost:5000


【添加电表】
  打开页面 → 点【电表配置】→ 依次选择：电表系统 > 校区 > 楼宇 >
  楼层 > 房间 > 电表 → 设置提醒阈值（默认 5 度）→ 点【保存电表配置】。


【接收低电量提醒】
  · 电脑端推送：在【设置】里打开「电脑端推送」（需在本机浏览器操作）。
  · 微信提醒（推荐手机用）：在【设置】→「微信推送」里按提示获取并填入
    Server酱 SendKey，即可把提醒发到你的微信。手机端推荐用这个。


【充值】
  在电表卡片点【充值】→ 输入度数 → 程序会打开学校官方支付页面，
  请在学校页面内完成支付。本程序不接触你的任何支付密码。


【升级为赞助用户（解锁更快查询间隔 / 多电表）】
  1. 打开【设置】→「赞助激活」，会看到【本机机器码】，点「复制」。
  2. 把机器码发给作者并完成赞助。
  3. 作者会回发一段「许可证」（以 XRTJ. 开头）。
  4. 把许可证粘贴到输入框，点【立即激活】即可。
  注意：许可证仅对你这台电脑有效，换电脑需重新签发。


【数据与隐私】
  · 程序运行后会在 exe 同级生成一个 data 文件夹（数据库、密钥）。
  · 所有数据只在你本机，卸载只需删除 exe 和 data 文件夹。
  · 请勿把 data 文件夹随程序转发给别人。


【常见问题】
  · 电量查询失败 → 检查是否连着北航校园网。
  · 页面打不开 → 手动访问 http://localhost:5000 ；或右键托盘图标「打开面板」。
  · 收不到微信 → 确认 Server酱 SendKey 填写完整、已发送过测试。
  · 想看运行日志 → 看 data 文件夹里的 run.log。
