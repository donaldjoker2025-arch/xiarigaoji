# ⚡ 夏日告急 — 北航空调电量监控

一个跑在你**自己电脑**上的小工具：定时查询宿舍 / 教研室电表剩余电量，电量偏低时通过 **电脑桌面通知 / 微信** 提醒你，并能一键跳转学校官方页面充值。

> 数据全部只存在你本机，不上传任何服务器。

---

## ✨ 功能

- 🔋 实时监控电表剩余电量，低于阈值自动提醒
- 🔔 多渠道提醒：电脑桌面通知、微信（Server酱）
- 💳 一键跳转学校官方页面充值（本程序不接触任何支付密码）
- 📈 电量趋势图、系统托盘常驻

| | 免费版 | 赞助版 |
|---|:---:|:---:|
| 监控电表数 | 1 个 | 最多 5 个 |
| 查询间隔 | 12 小时 | 可自定义（最快 2 小时）|

---

## 📥 下载与运行

1. 在本仓库下载 **`夏日告急.exe`**，放到一个可写文件夹（桌面 / 下载，**别放 `C:\Program Files`**）。
2. 双击运行。若提示「Windows 已保护你的电脑 / 未知发布者」，点 **更多信息 → 仍要运行**（本软件未购买代码签名证书，并非病毒）。
3. 程序会自动打开浏览器页面，右下角托盘出现闪电图标。

> ⚠️ **必须连接北航校园网**才能查到电量。详细步骤见 [使用说明.txt](使用说明.txt)。

---

## 💎 升级赞助版

1. 打开程序 → **设置 → 赞助激活**，复制你的 **本机机器码**。
2. 把机器码发到下方邮箱并完成赞助。
3. 收到回发的**许可证**后，粘贴激活即可。

> 许可证按机器绑定，仅对你这台电脑有效。
